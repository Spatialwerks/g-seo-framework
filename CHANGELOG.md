# LEGACY — G-SEO Framework Changelog

This changelog documents the historical development of the legacy G-SEO Framework.

The releases recorded here belong to the historical framework and should not be interpreted as versions or releases of the current G-SEO specification.

The legacy G-SEO Framework is no longer under active development.

Current G-SEO is a publisher-controlled implementation specification for generative search and information retrieval.

Current G-SEO information is maintained at:

https://g-seo.ai/

## Version 1.0

- Initial framework release
- Core structure defined
- Documentation and implementation layers established
