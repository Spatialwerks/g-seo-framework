# LEGACY — G-SEO Framework Documentation

This directory preserves supporting documentation associated with the legacy G-SEO Framework.

The documentation preserved here reflects the terminology, principles, scope, and normative language of the historical framework.

These materials are retained for historical reference and should not be interpreted as defining the current G-SEO specification.

Current G-SEO is a publisher-controlled implementation specification for generative search and information retrieval.

Current G-SEO information is maintained at:

https://g-seo.ai/
