# LEGACY — G-SEO Framework Implementation

This directory preserves implementation materials associated with the legacy G-SEO Framework.

These materials document the historical framework's implementation guidance, application workflows, example use cases, and scoring execution.

The implementation architecture described here is historical and should not be interpreted as defining implementation of the current G-SEO specification.

The legacy G-SEO Framework is no longer under active development.

Current G-SEO is a publisher-controlled implementation specification for generative search and information retrieval.

Current G-SEO information is maintained at:

https://g-seo.ai/
