# LEGACY — G-SEO Framework Core

This directory preserves the core materials of the legacy G-SEO Framework for historical reference.

These materials document the earlier framework architecture, including:

- Canonical Definition
- Framework Specification
- Framework Architecture
- Scoring Model

These materials are historical and should not be interpreted as defining the current G-SEO specification.

Current G-SEO is a publisher-controlled implementation specification for generative search and information retrieval.

Current G-SEO information is maintained at:

https://g-seo.ai/
