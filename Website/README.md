# LEGACY — G-SEO Framework Website

This directory preserves website-architecture materials associated with the legacy G-SEO Framework.

These materials reflect the historical framework's website architecture, page map, and public-facing content structure.

The website architecture described here is historical and should not be interpreted as defining the current G-SEO specification or the current G-SEO website.

The legacy G-SEO Framework is no longer under active development.

Current G-SEO is a publisher-controlled implementation specification for generative search and information retrieval.

Current G-SEO information is maintained at:

https://g-seo.ai/
