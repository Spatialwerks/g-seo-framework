# LEGACY — G-SEO Framework Governance

This directory preserves governance materials associated with the legacy G-SEO Framework.

The materials preserved here document the historical framework's governance structure, versioning model, release documentation, and authority statements.

These materials are retained for historical reference and should not be interpreted as defining the current G-SEO specification or its current lifecycle.

The legacy G-SEO Framework is no longer under active development.

Current G-SEO is a publisher-controlled implementation specification for generative search and information retrieval.

Current G-SEO information is maintained at:

https://g-seo.ai/
